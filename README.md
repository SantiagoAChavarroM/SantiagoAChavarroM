## Featured Projects

### Valen — AI Sales & Lead Generation Agent
AI agent that automates the full lead lifecycle for premium home-finishes businesses: captures leads from **Meta & Google Ads**, qualifies and nurtures them through **WhatsApp**, and hands off to the sales team.
> **Stack:** AI Agents · OpenAI · WhatsApp Business API · n8n · Node.js

### InventoryVoiceAgent — AI Inventory Management System
Full-stack inventory system with an AI assistant and **voice (TTS)** responses, built end to end as my Riwi capstone project.
> **Stack:** Node.js · Express · React · Vite · Tailwind · n8n · OpenAI (GPT-4o-mini) · TTS

### Post-Sale Automation System
Self-hosted automation for post-sale follow-up and customer service, integrating messaging, billing and notifications into a single flow.
> **Stack:** n8n (self-hosted) · WhatsApp Business API · OpenAI · Alegra · Telegram
